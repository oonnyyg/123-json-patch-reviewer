# json-patch-reviewer

仅使用 Go 标准库实现的 RFC 6902 JSON 补丁审查工具。支持预览与落盘两种模式，
不接入任何远程服务；任一步失败时整份补丁不生效，已有输出文件不会被覆盖。

## 用法

```sh
# 预览：审查报告打印到标准输出，不写任何文件
go run . -doc doc.json -patch patch.json

# 落盘：全部操作成功后才写入输出文件，并生成报告文件
go run . -doc doc.json -patch patch.json -out out.json -report report.json
```

参数：

- `-doc`：输入 JSON 文档路径（必填）
- `-patch`：JSON 补丁数组路径（必填）
- `-out`：落盘输出路径；缺省时仅预览
- `-report`：审查报告输出路径；缺省时打印到标准输出

## 支持范围

- 操作：`add` / `remove` / `replace` / `move` / `copy` / `test`，按补丁数组顺序
  依次作用于前一步结果；未知操作或缺少必要字段时报错并指出操作序号（从 1 开始）。
- 路径：RFC 6901 JSON Pointer。空路径表示根值；`~0` 转义 `~`，`~1` 转义 `/`。
  对象键按原文匹配；数组下标必须是不带前导零的十进制数且不得越界；
  `-` 仅允许用于数组追加位置；缺失的父节点不会自动创建。
- 数组语义：`add` 插入并后移后续元素；`remove` 后下标立即变化；
  `move` 先移除来源再定位目标，禁止移入自身后代；
  `copy` 深复制子树，不与来源共享可变状态。
- `test` 按 JSON 结构比较：对象键顺序无关，数组顺序相关，数值按数学值比较
  （`1` 等于 `1.0`），布尔值不等同于数值。
- 根值：允许用 `add`/`replace` 替换整个根值；拒绝删除或移动根值。
- 原子性：任一步失败则整份补丁不生效，原文档与已有输出文件保持原样；
  预览与落盘共用同一应用逻辑，结果一致。

## 审查报告

报告包含每一步的操作、操作后的完整文档（`steps[].document`）以及该步的
逆操作（`steps[].inverse`），并附最终文档（`final`）。将所有逆操作按相反
顺序执行可恢复原始文档（含数组顺序）。

## 测试

```sh
go test ./...
```

覆盖：波浪号转义键、数组插入/移动、中途 `test` 断言失败的原子性、
下标校验（前导零/越界/`-` 误用）、根值替换与删除、copy 深复制、
逆操作恢复、预览与落盘一致性、失败时不覆盖已有输出文件。
